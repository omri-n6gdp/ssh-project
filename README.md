# SSH Topolectrical Circuit — Project Folder

This project studies the **Su–Schrieffer–Heeger (SSH) topolectrical circuit**: a 1‑D
chain of LC resonators whose topological edge state shows up as an exponentially
decaying voltage profile along the chain. The work here measures how robust that
edge state is when impurities (modified capacitor bonds) are added.

## Folder map

| Folder | What's inside |
|--------|---------------|
| `netlists/` | LTspice schematics (`.asc`) and SPICE netlists (`.cir`) of the circuit. `netlists/Impurities/` holds the most recent circuits: `AB_3.3_2.2.asc` and `BA_3.3_2.2.asc` (the pair‑impurity chains). |
| `data/` | LTspice AC‑sweep exports (`.txt`): input impedance vs frequency for every impurity configuration. File names encode the impurity strength and position, e.g. `AB_-01gamma_-03delta_4.txt`. |
| `figures/` | Plots produced from the data. |
| `scripts/` | Python analysis + plotting scripts, plus spreadsheet sweeps. |
| `raw/` | Raw SPICE outputs (`.raw`) and Monte‑Carlo run files. |
| `docs/` | Written documentation: `robustness_manual.md` (the full method/theory write‑up) and `MonteCarlo_Report.md`. |
| `claude_ssh/` | A self‑contained, independent reconstruction of the whole study (its own solver, data, figures and report). Leave as‑is. |
| `reproduction/` | **New work:** a real‑SPICE (ngspice) reproduction of the target impurity figures, built from the most recent `netlists/Impurities` circuit. Has its own `netlists/`, `data/` and `figures/`. |
| `SSH_Robustness_Report.pdf` | Compiled report (generated by `scripts/build_report.py`). |

## The physics in one line

The chain alternates two capacitor values (3.3 nF and 2.2 nF). Because the bond
*leaving* the edge into the bulk is the weak one (2.2 nF), a topological edge mode
lives on the odd‑numbered nodes and decays by a factor 2.2/3.3 ≈ 0.667 per unit
cell — a straight line on a log plot. Impurities perturb this line locally; how
little they perturb it is the measure of topological robustness.
